# 季节装备系统说明

## 功能概述

角色装备会随着四季变化而自动改变，为游戏增加视觉丰富度和沉浸感。

### 4. 游戏逻辑集成

在 `game/game_logic.py` 中：

- 添加季节计时器和自动切换逻辑
- 在 `update()` 中更新季节并同步到所有玩家
- 在 `draw()` 中显示当前季节名称

```python
class Game:
    def __init__(self, ...):
        # 季节系统
        self.current_season = "spring"
        self.season_timer = 0
        self.season_cycle_time = 1800  # 30秒切换一次（60fps * 30）
    
    def update(self):
        # 更新季节系统
        self.season_timer += 1
        if self.season_timer >= self.season_cycle_time:
            self.season_timer = 0
            self.current_season = get_next_season(self.current_season)
            # 更新所有玩家的季节
            for player in self.players:
                player.set_season(self.current_season)
```

## 季节装备效果

### 春季
- **身体**：橄榄绿（适合草地环境）
- **枪械**：深灰色
- **装饰**：粉色花朵（头顶）

### 夏季
- **身体**：沙漠黄（适合炎热环境）
- **枪械**：棕色
- **装饰**：金色阳光（头顶）

### 秋季
- **身体**：棕色（适合森林环境）
- **枪械**：深棕色
- **装饰**：橙色叶子（头顶）

### 冬季
- **身体**：浅灰白（适合雪地环境）
- **枪械**：冷灰色
- **装饰**：蓝色冰晶（围巾）

## 使用方法

### 自动切换

游戏中季节会自动循环切换，默认每30秒切换一次。

### 手动测试

运行测试脚本：

```bash
python test_season_equipment.py
```

测试脚本会显示4个不同季节的玩家，按 **SPACE** 键可以切换所有玩家的季节。

## 技术细节

### 颜色格式

所有颜色使用 RGB 元组格式：`(R, G, B)`，每个值范围 0-255。

### 装饰绘制逻辑

在 `Player.draw()` 中，根据不同季节绘制不同的装饰：

- **春季**：圆形花朵
- **夏季**：太阳镜
- **秋季**：椭圆叶子
- **冬季**：围巾矩形条

### 网络同步

在多人联机模式下，季节状态通过 `serialize_state()` 和 `apply_state()` 自动同步到所有客户端。

## 注意事项

1. **性能**：季节切换逻辑在 `update` 中执行，确保不会影响游戏性能
2. **同步**：多人模式下确保季节状态正确同步
3. **兼容性**：保持与原有皮肤系统的兼容性
4. **可配置**：通过配置文件可以禁用或调整季节系统

## 总结

季节装备系统通过以下方式实现：

1. 在季节配置中添加装备颜色定义
2. 玩家实体根据季节动态选择颜色
3. 游戏逻辑自动循环切换季节
4. 视觉上呈现不同季节的装备效果

这个系统为游戏增加了视觉变化，提升了游戏的趣味性和沉浸感。
