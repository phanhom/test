# 项目概述

## 简介

这是一个基于 Pygame 开发的合金弹头风格横版射击游戏，支持单人游戏和多人联机模式。

## 主要特性

- **单人模式**：经典的横版射击闯关玩法
- **多人联机**：支持开房间多人联机（最多2人同时游戏）
- **地图系统**：5种不同风格的地图（训练场、沙漠前线、工厂废墟、雪地要塞、丛林基地）
- **皮肤系统**：可购买和切换角色皮肤
- **商店系统**：使用游戏金币购买皮肤
- **NPC系统**：集成大模型对话功能，可与NPC进行智能对话
- **广场大厅**：可走动的多人大厅，支持聊天、商店、NPC交互
- **四季系统**：自动循环的四季视觉效果
- **存档系统**：保存金币和已购皮肤

## 技术栈

- **Python 3.x**
- **Pygame 2.5.0+**：游戏引擎和图形渲染
- **Socket**：网络通信
- **JSON**：配置和数据存储

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置

复制配置模板并修改：

```bash
cp config.example.json config.json
```

编辑 `config.json`，配置NPC的API密钥等。

### 运行

```bash
python main.py
```

## 游戏模式

### 单人模式

- 从主菜单选择"单人游戏"
- 选择皮肤后开始游戏
- 通过5个关卡，难度递增

### 多人模式（主机）

- 从主菜单选择"创建房间"
- 进入大厅，等待其他玩家加入
- 显示房间码和IP地址
- 按Enter开始游戏

### 多人模式（客户端）

- 从主菜单选择"加入房间"
- 输入主机IP地址
- 进入大厅，按R准备
- 等待主机开始游戏

## 操作说明

- **P1**：WASD移动，J射击
- **P2**：方向键移动，K射击
- **R**：大厅中切换准备状态
- **ESC**：暂停游戏
- **鼠标**：点击NPC对话、打开商店、发送聊天消息
