# 核心模块说明

## 模块概述

`core/` 目录包含项目的核心功能模块，提供配置管理、存档系统、四季系统和商店系统等基础功能。

## 文件结构

```
core/
├── __init__.py
├── config_loader.py  # 配置加载器
├── save_data.py      # 存档管理
├── seasons.py        # 四季系统
└── shop.py           # 商店系统
```

## config_loader.py

### 功能

加载和管理游戏配置文件，提供统一的配置访问接口。

### 主要函数

#### `get_config()`

加载完整的配置文件。

```python
def get_config() -> dict
```

**返回**：配置字典

#### `get_lobby_config()`

获取大厅配置。

```python
def get_lobby_config() -> dict
```

**返回**：大厅配置，包含：
- `width`：大厅宽度
- `height`：大厅高度
- `max_players`：最大玩家数
- `world_width`：世界宽度

#### `get_game_config()`

获取游戏配置。

```python
def get_game_config() -> dict
```

**返回**：游戏配置，包含：
- `width`：游戏窗口宽度
- `height`：游戏窗口高度

#### `get_npc_config()`

获取NPC配置。

```python
def get_npc_config() -> dict
```

**返回**：NPC配置，包含：
- `enabled`：是否启用NPC
- `llm`：大模型配置
- `list`：NPC列表

#### `get_seasons_config()`

获取四季配置。

```python
def get_seasons_config() -> dict
```

**返回**：四季配置，包含：
- `enabled`：是否启用四季系统
- `current`：当前季节
- `cycle_seconds`：季节切换间隔（秒）

#### `get_shop_config()`

获取商店配置。

```python
def get_shop_config() -> dict
```

**返回**：商店配置，包含：
- `items`：商品列表

## save_data.py

### 功能

管理游戏存档，包括金币和已购皮肤。

### 主要函数

#### `load_save_data()`

加载存档数据。

```python
def load_save_data() -> dict
```

**返回**：存档字典，包含：
- `coins`：金币数量
- `purchased_skins`：已购皮肤ID列表

#### `save_save_data(data: dict)`

保存存档数据。

```python
def save_save_data(data: dict) -> bool
```

**参数**：
- `data`：要保存的存档字典

**返回**：是否保存成功

#### `get_coins()`

获取当前金币数量。

```python
def get_coins() -> int
```

**返回**：金币数量

#### `add_coins(amount: int)`

增加金币。

```python
def add_coins(amount: int) -> bool
```

**参数**：
- `amount`：要增加的金币数量

**返回**：是否成功

#### `add_coins_from_score(score: int)`

根据游戏得分增加金币（100分=1金币）。

```python
def add_coins_from_score(score: int) -> bool
```

**参数**：
- `score`：游戏得分

**返回**：是否成功

#### `purchase_skin(skin_id: int, price: int)`

购买皮肤。

```python
def purchase_skin(skin_id: int, price: int) -> bool
```

**参数**：
- `skin_id`：皮肤ID
- `price`：皮肤价格

**返回**：是否购买成功

#### `has_purchased_skin(skin_id: int)`

检查是否已购买皮肤。

```python
def has_purchased_skin(skin_id: int) -> bool
```

**参数**：
- `skin_id`：皮肤ID

**返回**：是否已购买

## seasons.py

### 功能

实现四季系统，提供季节切换和视觉效果。

### 主要类

#### `SeasonManager`

四季管理器。

**属性**：
- `current_season`：当前季节
- `last_change_time`：上次切换时间
- `cycle_seconds`：切换间隔

**方法**：

##### `update()`

更新季节状态。

```python
def update() -> None
```

##### `get_current_season()`

获取当前季节。

```python
def get_current_season() -> str
```

**返回**：季节名称（"spring", "summer", "autumn", "winter"）

##### `get_season_colors()`

获取当前季节的颜色配置。

```python
def get_season_colors() -> dict
```

**返回**：颜色字典，包含天空、地面等颜色

##### `get_season_particles()`

获取当前季节的粒子效果。

```python
def get_season_particles() -> list
```

**返回**：粒子列表

## shop.py

### 功能

实现商店系统，管理商品和购买逻辑。

### 主要类

#### `ShopItem`

商店商品。

**属性**：
- `skin_id`：皮肤ID
- `price`：价格
- `name`：商品名称
- `description`：商品描述

#### `Shop`

商店管理器。

**方法**：

##### `get_items()`

获取所有商品。

```python
def get_items() -> list[ShopItem]
```

**返回**：商品列表

##### `get_item(skin_id: int)`

获取指定商品。

```python
def get_item(skin_id: int) -> ShopItem | None
```

**参数**：
- `skin_id`：皮肤ID

**返回**：商品对象或None

##### `can_purchase(skin_id: int)`

检查是否可以购买。

```python
def can_purchase(skin_id: int) -> bool
```

**参数**：
- `skin_id`：皮肤ID

**返回**：是否可以购买

##### `purchase(skin_id: int)`

购买商品。

```python
def purchase(skin_id: int) -> bool
```

**参数**：
- `skin_id`：皮肤ID

**返回**：是否购买成功

## 使用示例

### 加载配置

```python
from core.config_loader import get_lobby_config, get_game_config

lobby_cfg = get_lobby_config()
game_cfg = get_game_config()

print(f"大厅尺寸: {lobby_cfg['width']}x{lobby_cfg['height']}")
print(f"游戏尺寸: {game_cfg['width']}x{game_cfg['height']}")
```

### 管理存档

```python
from core.save_data import get_coins, add_coins, purchase_skin

# 获取金币
coins = get_coins()
print(f"当前金币: {coins}")

# 增加金币
add_coins(100)

# 购买皮肤
if purchase_skin(1, 50):
    print("购买成功！")
```

### 使用四季系统

```python
from core.seasons import SeasonManager

season_manager = SeasonManager()
season_manager.update()

current = season_manager.get_current_season()
colors = season_manager.get_season_colors()
print(f"当前季节: {current}")
```

### 使用商店

```python
from core.shop import Shop

shop = Shop()
items = shop.get_items()

for item in items:
    print(f"{item.name}: {item.price} 金币")
```
